# 固定人物单件服装

适用：从已经批准的人物母版和风格参考，制作可独立穿戴的衣物。批量是重复执行单件闭环，不是生成一张服装九宫格。

## 开始前

- 读取母版、当前分层 manifest、用户本次款式清单。冻结人物画布、身体与姿势；不因为新衣服重画脸或身体。
- 区分三种结果：设计参考、已归位彩色穿戴图、已分离线稿/基色/阴影的可改色生产资产。当前做到哪一级就交付哪一级。
- 默认使用内置 image_gen 作创意出图或遮挡补画。精确裁切、alpha 清理、坐标归位、渲染和测量使用确定性脚本；用户要求固定画布切分时，不用 AI 反复重画整套代替切片。
- 本项目实例见 [references/shen-zhiwei.md](references/shen-zhiwei.md)。换人物时不能照搬实例坐标。

## 每一件的闭环

1. **规格**：分配稳定 ID，记录槽位、长度、轮廓、材质、颜色、锚点、遮挡关系。长裙/短裙/连衣裙分别管理；同款换色不能冒充不同款式。
2. **出图**：一件一次调用，附母版或风格参考；输出单件正面服装、真实透明背景、无人体/衣架/文字。提示词中保留哑光二次元画风和可独立穿戴的完整结构。记录实际提示词、参考文件、生成文件与工具模式。
3. **补全**：先补齐腰头、肩部、背带、袜脚等被遮挡区域；先前可见区域尽可能沿用批准原图。无法独立卸装的组合必须明确标记，不伪装成已拆开的商品。
4. **归位**：按母版肩/胸/腰/胯/膝/脚底定位，输出完整原始画布 PNG RGBA，不自动居中或裁小。独立生成的补画允许记录明确的坐标变换，但不得将其称作“原图无损切片”。裙腰必须贴合母版；连衣裙至少检查肩、胸、腰三处，不能只检查外框。
5. **穿戴拆层与技术检查**：完整展示图保留腰头/领口/袖口内侧；穿戴必须拆成前片与后片，后缘在身体后方，不能盖住肚子、脖颈或手臂。批次设 `requireWearablePartition: true`。详见 [references/worn-occlusion.md](references/worn-occlusion.md)。同时检查画布、alpha、孤立杂点、遮罩、文件完整性、实际归位锚点、透明边缘和是否夹带人脸/皮肤。阈值相对当前母版配置，不写死成所有人物通用标准。
6. **视觉检查**：打开该单件和实际试穿图；白/深色底检查边缘，100% 检查腰线/领口，手机尺度检查轮廓与材质。裙装至少分别测试有/无上衣；连衣裙卸掉上下装。宽裙需让手在衣服前，不把手切掉。发现拉伸、露内衣、遮挡错位、断片或白边，修正后重新生成证据图。
7. **记录**：保存 `item.json` 与 `qa.json`，技术通过和视觉通过分别记录。只有实际检查过的文件才能设 `visual_reviewed=true`。`wearable_validated=true` 只代表当前母版试穿合格，不自动代表通用适配或已可改色。
8. **下一件**：当前件未通过时先修当前件。重试应针对已发现的问题；外部工具失败时保留已完成项及可恢复的任务清单，不能把缺失项计为完成。

具体拆层、改色与验收标准见 [references/production-sop.md](references/production-sop.md)。

用户指定先线稿后填色时，生产顺序为：单件线稿 → 母版试穿校验 → 基色分区 → 阴影层 → 再次验收。保留独立线稿、区域遮罩和阴影；不能把彩色 PNG 自动去色的结果冒充原始线稿。本项目已有彩色素材可先验证穿戴，但必须明确标注尚未完成可改色分层。

## 脚本

先调用 `load_workspace_dependencies` 定位 bundled Node 包，将 `DRESSUP_NODE_MODULES` 指向返回的 node_modules。不要安装不明依赖或修改运行时目录。

配置字段及本工程适配范围见 [references/batch-schema.md](references/batch-schema.md)。

`node scripts/register.cjs <batch.json> <item-id>`：读取任务定义和单件原稿，导出同画布穿戴层、alpha 遮罩、正反底单件证据、试穿证据及技术检查。脚本不代替视觉签收；初次归位后按实际图像调整源锚点再重跑。

`node scripts/accept.cjs <batch.json> <item-id> "实际观察记录"`：仅在打开并检查该件证据图后签收；技术失败或证据变动时拒绝签收。

`node scripts/validate-batch.cjs <batch.json>`：核对数量、每款唯一 ID、文件、技术结果及逐件视觉签收；缺失或未通过项返回非零退出码。

## 批量交付

保留每件的原稿、归位层、遮罩、源锚点/变换、技术检查和试穿证据。提供按类别浏览、单件开关、上下装互斥和原画布下载的预览。若用户要求每类五款，必须分别满足三个类别数量，不用总数凑数。归位失败的漂亮原稿不计入完成数。
