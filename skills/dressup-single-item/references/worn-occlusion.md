# 正面可见衣片与内片排查

本用户最新要求：所有衣服都不画内片。旧流程“完整展示图保留内片，再拆后层”已停用，不可因文件格式、立体感或重新生成恢复。

front 只包含正面可见衣料，back 为全透明占位。领口后圈、腰后弧、袖裤口内筒、后翻片、里衬、衣摆背面、开襟内连接左右前襟的背布均删除。正面翻领、正面褶皱与阴影仍保留。独立内搭是另一件装备，不烘焙到衣服。

删除内片按实际结构绘制局部遮罩；不能一条水平线切掉整个领子，不能让腰线下移产生露肤缝。删除后需要真正布料才能衔接时，在批准的服装轮廓内用 image_gen 补画，而非取色扩边。不能补画后片来闭合。

半透明纱/蕾丝保留真实 alpha，开口是透明负形，不补肤色。只把 back 清空不证明 front 已无内片，必须打开前片、浅深底和人物100%局部检查。

程序可检查 back alpha 全零，以及手工定义的 forbidden 区域没有像素；无法从一般 alpha 自动识别全部内片。实际验收还要检查肩腋、双侧袖内缘、袖口、腰口和下摆；长裙的手部前景由现有渲染器处理，不增加衣服内片。
