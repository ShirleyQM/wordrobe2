# 展示图与穿戴层

完整单件图用于商品展示，不能直接把它盖在身体上当作穿戴图。空挂服装常画出腰头、领口、袖口的内侧与后缘；穿上后，这些区域应在身体后方，前片只能保留正面可见的部分。

每件保存三类文件：完整展示图、穿戴前层、穿戴后层。三者使用相同母版画布；按实际轮廓描出后缘遮罩，用 alpha 分区保留原 RGB。不能用一条水平线粗暴截掉整个领子，也不能删掉后片后让腰线下移产生露肤缝隙。以穿戴前腰线、颈根和腕口重新校准锚点，记录展示与穿戴的坐标差异。

渲染顺序：后发 → 服装后片 → 身体 → 袜子 → 服装前片 → 搭配上衣（裙装） → 鞋 → 手部前景 → 包/首饰 → 前发。包带有后段时也应拆前后层。

验收：先单看前层，腰头应只有前弧、领口应有实际透明开口；再试穿，脖子与手臂不能被后领、袖筒内侧盖住；腰头后缘不能横穿肚子。检查领口与袖口开口内的母版内衣是否露出。裙装分别试有/无上衣，重新确认前腰线与上衣下摆衔接。

至少保存浅深底前片、同尺寸后片、局部放大试穿和整身试穿；技术检查可验证 alpha 分区前后相加等于展示源、RGB 保留以及样本后缘像素不在前层，但穿插和造型仍需视觉检查。

本工程实现与逐件路径记录：项目 `assets/skirt-collection-v1/build-wearable-layers.cjs` 与每件的 `wearable-qa.json`。其中路径属于沈知微母版，换角色必须重描。批次应设置 `requireWearablePartition: true`，签收与总验收会核对前后层文件及哈希，未完成穿戴拆层不通过。
