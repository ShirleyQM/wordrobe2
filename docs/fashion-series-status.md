# 移动端系列、卡片与服装

主入口仍为 `mobile.html`。卡册与学习沿用原顶部导航、积分和穿搭状态；不新增平行游戏页面。

`assets/fashion-series/catalog.json` 是系列及关联名称的统一索引：30 个系列、90 张正式卡面、122 件独立服装/鞋头/饰品稿。卡片 ID 沿用 `Sxx-Fxx`，不因展示顺序改变。共享单品保留一个 ID，通过 `seriesIds` / `cardIds` 记录复用。

## 当前呈现

- 复古未来 S04：完整接入六关，原解锁顺序、成绩、积分及第 2/4/6 关的卡片奖励不变。
- 卡面与服装正面稿齐全的十个系列排在前面：复古未来、球衣混搭、独立摇滚、都市张扬、意式假日、现代旗袍、海边日常、网球俱乐部、City Pop、马术语汇。
- 其余二十个系列默认收进「后续系列」，保留系列名、数量及设计预告，展开后可查看卡面。
- 学习页首先呈现已开放的 Y2K 六关；原三十关语境阅读仍可从折叠目录进入。其余二十九个主题显示筹备进度与卡片入口，不呈现假的开始按钮。
- 正面美术稿不等于可穿戴资产。未出现在当前可见衣橱中的稿件显示「服装待上线」，不发放到玩家背包，也不开放兑换。

## 服装命名与来源

已在索引中的单品使用制作清单的完整名称，不再被旧清理函数删掉颜色等辨识信息。玩家自定义名字优先且不改写。已导入单品也可用 `sourceCard`、`sourceCardId`、`cardId`、`fashionCardId`、`sourceCards` 或 `source.cardId` 明确关联正式卡片；只认有效的 `Sxx-Fxx`，不按名字猜测系列。

卡片详情显示系列、正式卡名、卡号、对应单品与参考品牌。现有可见衣橱单品可以返回试穿；草稿仅展示。旧 `Cxx-*` 概念卡 ID 与收藏记录保留，已拥有的旧卡出现在「早期设计收藏」，不覆盖或重命名存档。

## 手机资源与回归

界面使用独立 WebP 预览（90 张卡面与 122 件单品约 10 MB），原始 PNG 仍在既有美术档案中，字节不变。预览放在 `assets/`，沿用 GitHub Pages 的原媒体哈希发布流程。

运行 `node test-fashion-series.cjs` 检查排序、卡片/服装对应、球衣组全球鞋、未上线资产不能兑换，以及旧收藏、穿搭、进度和自定义名字保持。
