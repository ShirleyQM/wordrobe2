# 沈知微实例

母版：项目 `assets/gentle-campus-v2/sources/base.png`；已切身体/发型：`assets/gentle-campus-v2/layers/`。
画布 939×1676，原点左上。发型中分露额，蓝黑长发，前后发分别叠加；成年角色，画风清淡、哑光二次元，不加油亮皮肤或高反光材质。

当前用于裙装的腰线 y565，腰中心 x469，目标腰宽约180px；仅用于这一母版。上衣组合件在腰线附近收口。短裙裙摆约 y880–980；长裙约 y1250–1410。连衣裙从肩颈约 y305–325 到腰 y565，必须用实际母版试穿验证。

层级：后发 → 身体/基础内搭 → 袜 → 下装或连衣裙 → 上衣（裙装可选）→ 鞋 → 包/首饰 → 前发 → 必要的手部前景。连衣裙穿戴时移除上衣与下装；基础内衣不能从领口和袖窿漏出，需要高覆盖领型或专用合法身体遮挡/补画。

此前已经证实的失败：AI 声称同画布提取但会放大衣服；仅检查尺寸不够。裙腰/袜脚被遮住时，只裁可见区域会留下缺片。原图彩色切片也不能当作可自由改色素材。切件不改源 RGB，只能证明切片步骤；不能证明补画源本身与母版完全一致。
