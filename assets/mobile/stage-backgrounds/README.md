# 换装背景 · 低干扰时尚场景

四张背景：银蓝摄影棚（默认）、午夜秀场、雨后街拍、艺术开幕夜。均由内置 image_gen 生成；manifest.json 保留完整提示词与图片 SHA-256。原图保留生成字节。

运行入口：mobile.html 中人物区右上角“场景”。四种背景均可直接切换，不使用积分。中央保留人物展示空间，装饰位于边缘，背景不跟随人物近景缩放。

当前选择与衣橱 state 一起保存；收藏／心愿搭配与撤销快照携带 sceneId。恢复不含 sceneId 的旧收藏采用银蓝摄影棚，服装与已拥有状态沿用原逻辑。脱衣或重置穿搭不改背景。

收藏缩略图先绘制所选背景，再绘制原有服装和人物图层；选择时捕获 sceneId，保存过程中切换背景不更改已捕获的收藏背景。图片无法载入时使用该场景的低干扰底色，选择器提示可重试。

stage-scenes.js 独立提供场景选择器与 canvas 背景绘制，look-lab.js 仅加入快照与缩略图接口。GitHub Pages 构建沿用原媒体映射机制，无需复制游戏到本地。

验证：node test-stage-scenes.cjs。覆盖旧存档默认值、切换、撤销检查点、背景请求竞态、裁切、缩略图与图片加载失败。实际手机视窗还需查看人物与工具栏位置。
