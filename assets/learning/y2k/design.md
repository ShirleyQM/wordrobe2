# Y2K 正式关卡接入

入口：learn.html 的 Cyber Y2K 区块，或 learn.html?chapter=y2k。六个小关复用已编写的12件单品教学、24核心词、8拓展词、4篇全文和48道练习；12道随堂练习不计分，36道关卡题沿用4/6通关规则。

每关首次通过获得现有游戏钱包50积分，六关共300积分；信用ID y2k-course-v1:level-N 防止重玩或中断恢复重复发奖。原有XP与星级仅表示本节练习表现，不兑换积分。积分和卡片分步到账，中断时重新进入或点重试可补齐，不重复给积分。

第2、4、6关分别获得S04-F01、S04-F02、S04-F03，归入主游戏CardLibrary。卡面展示使用完整独立插画，不使用旧拼图坐标；卡面服装尚无对应可穿图层，关联服装清单保持空，不虚构到账衣服。旧9张卡与旧关卡、余额保留。

关卡存档使用wordrobe-y2k-course-v1，独立试玩的存档与素材保持原样。静态Pages发布会复制assets内的课程和插画，入口先经过现有learn.html启动页，保持媒体映射与钱包一致。

新手胶囊：白色短衬衫、靛蓝排扣开衩裙、黑色芭蕾鞋、银色几何耳饰；替换款为可染色基础T恤和窄直筒长裤。新用户默认穿前四件，另外两件在衣橱；只为内衣裤保留基础款兜底，不再按每个分类赠送两件最低价物品。旧赠品和已购衣服不回收，不强改旧玩家当前穿搭；衣橱“新手搭配”按钮可主动试穿并撤销。

染色角标严格依据 runtime capabilities.recolor===true 显示，不凭面料名、价格或缩略图推断。印花标识仍使用独立能力字段。角标标示单品能力，不替代裁缝铺和衣服的解锁条件。

验证：node test-y2k-runtime.cjs；覆盖新旧赠品、积分重复结算、中断恢复、卡册登记、染色能力真假及语法。未拉取或克隆游戏到本地，代码检查在内存中进行。
